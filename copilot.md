This is a mini code agent that follows component architecture. However, it lacks the agent skills component. 

The goal is to create this new component. The mini code agent must be able to identify a folder skill (such as \skill\pr-review) and trigger a skill.md file by executing the instructions when an appropriate prompt is triggered or when the code agent needs a specific agent skill during execution.  

The component must log the prompt, the similarity check, and the executed skill. 

For this, follow a SDLC for code agents by including in your projects files (e.g. intend.md, spec.md, plan.md) to represent SDLC stages.
